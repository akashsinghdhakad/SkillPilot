SkillPilot – Modular SaaS Learning Platform
Product Architecture & Development Document
1. Product Overview
SkillPilot is a multi-tenant modular SaaS platform that enables organizations, educators, and training institutes to create, manage, and sell online courses.
The platform supports:
Course creation and management
Student learning management
Certificate generation
License-based SaaS distribution
Role-based access control
Modular feature architecture
Multi-tenant isolation
SkillPilot is designed as a reusable SaaS product, meaning multiple clients can use the same system while keeping their data completely separated.
2. Product Vision
SkillPilot aims to become a complete learning and skill management ecosystem.
The platform will allow:
Trainers to monetize courses
Institutions to manage LMS systems
Corporations to run internal training
Entrepreneurs to launch white-label course platforms
The architecture prioritizes:
scalability
modular development
SaaS monetization
feature extensibility

Each client is represented by a Tenant.

Data separation is handled using:

Every tenant-owned table contains this field.
5. Modular SaaS Architecture
SkillPilot is designed using modular architecture, where each major feature is developed as an independent module.
This allows:
independent development
easier maintenance
plugin-like features
package-based feature enable/disable

9. API Request Flow
Every protected API follows this sequence:
Client Request      ↓Authentication (Sanctum)      ↓ResolveTenant Middleware      ↓CheckLicense Middleware      ↓Role Authorization      ↓Controller      ↓Database Query
This ensures:
user is authenticated
tenant is valid
license is active
user has proper permissions

14. Security Principles
SkillPilot enforces strict multi-tenant security.
Rules:
All tenant-owned tables include tenant_id
Middleware validates tenant
License validation required
Role-based permissions enforced
Passwords securely hashed
Example secure query:
Course::where('tenant_id', tenant_id)->get();

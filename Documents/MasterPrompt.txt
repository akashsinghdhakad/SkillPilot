You are a senior SaaS architect and full-stack developer.

Your task is to generate a complete modular SaaS application called "SkillPilot".

SkillPilot is a multi-tenant learning management SaaS platform where organizations can create and sell courses, manage users, and issue certificates.

The application must follow clean architecture, modular design, and best practices.

--------------------------------------------------

PROJECT OVERVIEW

Product Name: SkillPilot

Purpose:
A SaaS learning platform that allows multiple organizations (tenants) to manage courses, students, instructors, certificates, and payments.

Architecture requirements:

- Modular architecture
- Single database multi-tenant model
- License-based SaaS distribution
- Feature flag system for packages
- REST API backend
- Frontend dashboard

--------------------------------------------------

TECH STACK

Backend
- Laravel 12
- PHP 8.2+
- MySQL
- Laravel Sanctum authentication
- nwidart/laravel-modules for modular architecture

Frontend
- Next.js (React)
- TailwindCSS
- Axios API client

Infrastructure
- Redis (optional caching)
- S3 storage for files
- Docker compatible

MULTI TENANT MODEL

SkillPilot uses a single database multi-tenant architecture.

Each client is represented as a tenant.

All tenant-owned data must include:

tenant_id

Tenant-owned tables:

users
courses
course_sections
course_lessons
course_progress
certificates
orders
payments

Tables without tenant_id:

roles
packages

LICENSE SYSTEM

Each tenant must have an active license.

License properties:

tenant_id
package_id
expires_at
is_active

If license is expired, block API requests.

--------------------------------------------------

FEATURE FLAG SYSTEM

Packages define features using JSON.

Example:

{
 "courses": true,
 "certificates": true,
 "affiliate": false
}

Create helper:

feature_enabled("affiliate")

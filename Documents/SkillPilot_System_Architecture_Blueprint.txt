SkillPilot – System Architecture Blueprint
1. System Overview
SkillPilot is a multi-tenant modular SaaS learning platform designed to allow organizations and trainers to create, sell, and manage online courses with certificate generation and license-based access control.
The system follows these architectural principles:
Modular architecture
Single database multi-tenant model
License-based SaaS distribution
API-first backend
Role-based access control
Feature flag monetization
2. High-Level System Architecture
Users   │   ▼Frontend (Next.js)   │   ▼API Gateway (Laravel Routes)   │   ▼Middleware Layer ├ Authentication (Sanctum) ├ Tenant Resolver ├ License Validator └ Role Authorization   │   ▼Application Modules ├ Auth ├ Tenants ├ Licenses ├ Courses ├ Certificates ├ Payments └ Affiliate   │   ▼Database (MySQL)

4. Tenant Lifecycle
1. Client Purchases SkillPilot
Admin creates tenant.
Tenant Created↓License Assigned↓Admin User Created↓Tenant Platform Activated
2. Tenant Adds Users
Tenant admin can create:
instructors
students
staff
3. Tenant Creates Courses
Instructor builds:
Course ├ Sections └ Lessons
Students enroll and progress is tracked.
4. Course Completion
Upon completion:
Course Completed↓Certificate Generated↓Stored in Certificates Table
5. Request Flow
Every protected API follows this flow:
Client Request      ↓Auth Middleware      ↓Resolve Tenant Middleware      ↓License Validation Middleware      ↓Role Permission Middleware      ↓Controller      ↓Service Layer      ↓Database
This ensures:
user authenticated
tenant valid
license active
permissions checked
